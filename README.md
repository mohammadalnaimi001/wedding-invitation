# دعوة زفاف أحمد وأميرته

دعوة عربية باتجاه RTL بتصميم عاجي وذهبي: ظرف مجسّم متحرك، موسيقى أصلية، آية افتتاحية، أسماء بخط عربي، عدّ تنازلي، خريطة القاعة، ليلة الحناء، تنبيه التصوير، مشاركة وتقويم.

## تشغيل المشروع

تحتاج Node.js 22.13 أو أحدث وpnpm.

```bash
corepack enable
pnpm install
pnpm dev:next
```

افتح `http://localhost:3000`.

## تغيير تفاصيل المناسبة

كل بيانات المناسبة في `lib/wedding-config.ts`:

- النص داخل ختم الظرف وأعلى الصفحة في `monogram`، وقيمته الحالية `A & M`.
- الأسماء والآباء، التاريخ ووقت البداية والنهاية.
- المنطقة الزمنية `Asia/Amman` والإزاحة `+03:00`.
- اسم القاعة والعنوان ورابط Google Maps ورابط الخريطة المضمنة.
- تاريخ الحناء ومكانها: ديوان الملكاوي – طبربور، ورابط الموقع في `hennaMapsUrl`.
- زفّة العريس في يوم العرس نفسه: وقتها `groomZaffaTime` مضبوط على `17:00`، ورابط موقعها في `groomZaffaMapsUrl`.
- اسم الفنان، تنبيه التصوير، مسار الموسيقى ورابط الموقع.

بعد نقل الدعوة إلى نطاق آخر، غيّر `siteUrl` إلى الرابط النهائي وأعد البناء؛ يستخدمه زر المشاركة ووسوم معاينة واتساب. غيّر `groomShortName` مع `groomName` إذا بدّلت اسم العريس. عند تغيير بيانات الصورة الاجتماعية، حدّث `public/og.png` لتطابق المناسبة.

## الموسيقى

المسار `public/audio/wedding.mp3` يحتوي مقطوعة أصلية آلية هادئة مدتها 54 ثانية، وليست تسجيلًا للفنان يوسف الشيخ. يمكن استبدال الملف بملف MP3 آخر تملك حق استخدامه مع الاحتفاظ بالاسم. لا يبدأ التشغيل قبل الضغط على «افتح الدعوة». زر الصوت يوقف ويستأنف التشغيل، ويتوقف الصوت عند إخفاء الصفحة.

سكريبت `scripts/generate-audio.py` هو مصدر المقطوعة اختياريًا، ويحتاج Python وNumPy وFFmpeg عند إعادة توليدها فقط؛ ليس من متطلبات تشغيل الموقع.

## Vercel

اربط مستودع المشروع. إعدادات `vercel.json` مضبوطة مسبقًا:

- أمر البناء: `pnpm exec next build`
- مجلد النتيجة: `out`
- لا يحتاج المشروع مفتاح API أو قاعدة بيانات.

## Netlify

اربط المشروع، وسيستخدم `netlify.toml` أمر البناء نفسه ومجلد `out`.

أو ابْنِ محليًا ثم ارفع محتويات `out` إلى استضافة ملفات ثابتة:

```bash
pnpm build:next
pnpm start
```

أمر `pnpm start` يعرض النسخة المبنية على `http://localhost:3000`.

ملفات `vite.config.ts` و`build/` وسكربتات Sites مخصصة لبناء ومعاينة النسخة المنشورة هنا، أما استضافة Vercel وNetlify فتستخدم Next.js مباشرة.

## التحقق

```bash
pnpm check
```

يتحقق من TypeScript وأوقات عمّان، بداية/نهاية العدّ التنازلي، تواريخ تقويم Google، ملف ICS وتقسيم أسطر UTF-8، ووجود الأصول المطلوبة.

فُحصت الدعوة في متصفح Chromium على سطح المكتب وعروض 360 و375 و390 و412 و430 بكسل، دون تمرير أفقي. فُحصت الافتتاحية، الصوت، التقويم والخريطة. هذه محاكاة لأحجام الشاشة، وليست تجربة على أجهزة iPhone وAndroid فعلية. يدعم التصميم `prefers-reduced-motion` ولوحة المفاتيح وقارئات الشاشة.

لا يوجد ضمان رقمي لمعدل 60 إطارًا؛ تُستخدم حركة CSS خفيفة، ويُوقف تحريك العناصر عند إخفاء الصفحة. الخطوط والصور والصوت محلية، والخريطة تُحمّل عند الاقتراب منها.

## الأصول

- `public/fonts/`: Amiri وAref Ruqaa وNoto Sans Arabic مع تراخيص SIL OFL.
- `public/images/botanical.webp`: زخارف مولدة لهذه الدعوة.
- `public/og.png`: بطاقة معاينة للمشاركة، 1200 × 630.
- `public/audio/wedding.mp3`: مقطوعة أصلية لهذه الدعوة.

لا تُرسل رسائل أو دعوات تلقائيًا. أزرار المشاركة والتقويم تبدأ باختيار الضيف، ورابط الموقع قابل للمشاركة.
